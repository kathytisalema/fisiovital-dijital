
# Plan de comunicación y presupuesto

## Presupuesto desglosado

| Partida | Importe estimado |
|---|---:|
| Análisis y diseño | 5.000 € |
| Desarrollo e implantación | 15.000 € |
| Migración de datos | 4.000 € |
| Formación y documentación | 3.000 € |
| Contingencias | 3.000 € |
| **Total estimado** | **25.000 € – 35.000 €** |

## Resumen

El presupuesto total estimado del proyecto es de **25.000 € – 35.000 €**, en línea con el Project Charter. Esta estimación cubre análisis y diseño, desarrollo e implantación, migración de datos, formación y documentación, y una reserva de contingencia para riesgos e imprevistos.

El plan de comunicación se diseñó para asegurar el seguimiento continuo del proyecto, la gestión de incidencias y la validación del alcance, con canales definidos para el cliente, el equipo técnico y los responsables de gobernanza.
