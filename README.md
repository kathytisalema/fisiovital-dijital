# FisioVital Digital

Proyecto de gestión documental del curso IFCT055PO.
Jefe de Proyecto: Katherine Tisalema

## Descripción del Proyecto

FisioVital Digital es un proyecto de transformación digital orientado a la implementación de una plataforma web, para  una red de clinicas de fisioterapia. 

## Objetivo del Proyecto

Sustiruir los procesos manuales y herramientas basadas en hojas de cálculo por una plataforma centralizada que permita registro de pacientes, citas, historial clinico y facturación de una forma segura y eficiente.
